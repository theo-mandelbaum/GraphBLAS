Analysis outputs
================

This folder stores profiling reports and summaries generated by `run_analysis.sh`.

Usage
-----
Run `../run_analysis.sh` from `GraphBLAS/profiling`.

Typical files
--------------
  perf.data                   - perf capture
  perf_report.txt             - perf report summary
  memory_usage.txt            - peak memory and elapsed time
  scaling_results.csv         - strong scaling timing results
  code_metrics.txt            - counts of OpenMP pragmas and related metrics

This directory exists to keep analysis outputs separate from the benchmark data.
